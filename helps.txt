GameVerse 2.0 — версия для GitHub Pages

Все файлы размещены рядом с index.html, без вложенных папок.

СТРАНИЦЫ
index.html — главная страница, игры и категории.
library.html — библиотека игр.
download.html — загрузки (демонстрационные данные).
community.html — сообщество.
profile.html — профиль (макет).
notifications.html — уведомления (макет).
login.html — форма входа (макет).
register.html — форма регистрации (макет).

СТИЛИ
Файлы *.css лежат в корне. Например, global.css, style.css,
responsive.css, improvements.css, stage2.css.

ШРИФТЫ И КАРТИНКИ
Шрифты Manrope-*.ttf и Unbounded-*.ttf, изображения logo.png,
avatars.png, avatars.jpg тоже находятся рядом с index.html.

ЧТО БЫЛО ИСПРАВЛЕНО
Пути к стилям, изображениям и шрифтам изменены на прямые.
Аватар теперь загружается с правильным именем avatars.png.

КАК ОПУБЛИКОВАТЬ
1. Создать публичный репозиторий на GitHub.
2. Загрузить СОДЕРЖИМОЕ ZIP-архива в корень репозитория.
3. Settings > Pages > Deploy from a branch > main / (root) > Save.
4. Адрес будет https://USERNAME.github.io/REPOSITORY/.

ВАЖНО
GitHub Pages — статический хостинг. Без JavaScript и сервера
вход/регистрация, сохранения игр, сортировка, поиск и настройки
профиля не будут функциональны — это пока демонстрационный интерфейс.
Изображения игр и иконки из внешних сервисов требуют интернет.
