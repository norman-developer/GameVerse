# GameVerse 2.0

Вариант сайта для публикации на GitHub Pages. Все файлы лежат **в корне репозитория**, включая CSS, шрифты и картинки. Главная страница — `index.html`.

## Как опубликовать

1. Создайте репозиторий на GitHub.
2. Загрузите **все файлы из ZIP**, не сам ZIP, через **Add file → Upload files**. Убедитесь, что `index.html` находится в корне.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Выберите **main** и **/(root)**, сохраните.
5. Ссылка будет вида `https://USERNAME.github.io/REPOSITORY/`.

## Примечание

В архиве сохранён статический HTML/CSS-дизайн. Поиск, добавление игр в библиотеку, настройки профиля и регистрация требуют JavaScript и/или сервера и пока являются макетами. Карточки игр и иконки загружаются с внешних сайтов, поэтому для них требуется интернет.
